# حجز رقم شركات المقاولات

> منصة إلكترونية لحجز أرقام شركات المقاولات بسهولة وأمان

## الصفحات

| الصفحة | الرابط | الوصف |
|--------|--------|-------|
| صفحة الحجز | `/` | نموذج تسجيل بيانات الشركة |
| لوحة التحكم | `/admin` | إدارة الحجوزات وأوقات العمل |

## المميزات

- **حجز رقم** — إدخال اسم الشركة، رقم الهاتف، والرقم القومي للمسؤول
- **لوحة تحكم** — عرض وإدارة جميع الحجوزات
- **أوقات العمل** — تحديد الأيام والأوقات المتاحة للحجز
- **تصدير CSV** — تصدير جميع الحجوزات لملف Excel
- **بحث وحذف** — البحث في الحجوزات وحذفها
- **واجهة عربية RTL** — تصميم متجاوب بالكامل بالعربي

## بيانات الدخول للوحة التحكم

```
كلمة المرور الافتراضية: admin123
```

> **ملاحظة:** يمكن تغيير كلمة المرور من قسم الإعدادات داخل لوحة التحكم

## التقنيات المستخدمة

- **HTML5** — بنية الصفحات
- **CSS3** — التصميم والأنيميشن
- **Vanilla JavaScript** — المنطق والتفاعلية
- **localStorage** — حفظ البيانات محلياً في المتصفح

## ملاحظة مهمة

البيانات تُحفظ في `localStorage` الخاص بالمتصفح، مما يعني:
- كل مستخدم يرى بياناته الخاصة فقط
- للحصول على قاعدة بيانات مشتركة، يجب ربط المشروع بـ backend

## الرفع على Vercel

1. ارفع المشروع على GitHub
2. افتح [vercel.com](https://vercel.com) وسجّل دخولك
3. اختر "Add New Project" واختر الـ repo
4. اضغط Deploy — خلاص!
